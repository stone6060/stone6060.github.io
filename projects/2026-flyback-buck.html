LM5164 反激-降压复合电源

60V 输入双路输出电源板
独立设计（原理图 + PCB + 打样验证）2026-09 – 2026-10 1 人团队

用一颗 LM5164 同时做降压主输出和反激辅输出。主路 VOUT 为同步降压，辅路借同一开关节点驱动定制变压器产生 VOUT_FLYBACK，实现单芯片双路输出；板载 RESR 模拟电阻与 CFF 前馈电容，便于环路稳定性实测。

技术要点

用一颗 LM5164 实现「降压 + 反激」双路输出：主路同步降压，辅路借同一开关节点驱动定制变压器做反激

LM5164 原本是同步降压控制器。把 SW 节点同时接到变压器初级，利用开关管的关断反峰经变压器耦合到次级，整流后得到独立的 VOUT_FLYBACK。这样省掉一颗独立反激控制器，代价是两路输出共用占空比。

电源设计拓扑创新

板载 RESR（47mΩ）等效串联电阻模拟电路，用于注入扰动做环路稳定性实测

输出电容串一颗已知阻值的采样电阻，配合示波器可测输出阻抗与相位裕度，把「环路稳不稳」从仿真变成板上可测的量。

电源设计测试方法

加入 CFF（22pF）前馈电容改善瞬态响应，并用 453K / 49.9K 分压设定输出

RFB1/RFB2 = 453K/49.9K，分压比约 9.08:1；CFF 与 RFB1 并联，在高频段提供旁路通路，抵消反馈网络带来的相位滞后。

电源设计环路补偿

示波器实测开关波形：通道 1 测到 293.392 kHz 开关频率、周期 3.820μs，Vpp 12.4V，下降时间 50.00ns

实测确认电路进入稳定开关状态，频率落在设计预期范围内。波形上的尖峰为开关管关断瞬间的漏感反峰。

测试实测验证

完成 PCB Layout 并实板调试：四角 M3 固定与接地、输入/输出端子分区布置、丝印标注各功能块

板子按功能分区：左侧输入（VIN/CIN1/CIN2），中部 LM5164 + 变压器，右侧 VOUT 与 VOUT_FLYBACK 两个输出区。四角螺柱既做机械固定也做接地。

PCBLayout

过程中尝试过 LM5176 四开关升降压方案后放弃，改用 LM5164 单芯片双路方案

工程里保留了 Schematic1（LM5176 + 外置 N/P MOS）作为早期尝试。LM5176 需要外置四颗开关管和更复杂的驱动，对单板双路输出而言 LM5164 方案更简洁。
